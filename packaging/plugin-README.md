# Know Your Unknowns (unknowns)

Eleven skills for the unknowns in a task, in any domain: what you don't know, what the AI doesn't know, and what neither of you knows yet. They find blind spots on both sides, teach a field's vocabulary, ask what the AI cannot know, compare options, plan, record deviations, surface what approvers don't know, and check understanding. The unknowns-loop skill threads these methods together before, during, and after the work, and ends by checking with you whether the result achieved the outcome. Self-evident requests are done directly, without the skills. Deliverables are Markdown in the conversation. Claude Code also gets two agents, for investigation and for checking evidence. Recording deviations is part of the skill instructions.

For installation, worked examples, limitations, and attribution, read the [repository README](https://github.com/ajitta/know-your-unknowns#readme).
