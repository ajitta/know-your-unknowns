The user wants to start a neighbourhood tool library in their apartment complex's
unused storage room, run by volunteers and open two evenings a week. The reply must
cover four things. An item counts when the reply asks the user for it, or states it as
a draft or an assumption; naming it only as something to settle later does not count.
All of these must hold:

1. The outcome the user is ultimately after: what the library is for (for example
   neighbours borrowing instead of buying, saving money and storage space, neighbours
   getting to know each other), not only opening it.
2. The done criteria: what must be true for the library to count as launched or
   working (for example the room approved for this use, a first set of tools, enough
   volunteers for both evenings, a first opening date).
3. What already works and must not break (for example the building's rules or the
   relationship with management, the neighbours' quiet in the evenings, the
   volunteers' other commitments).
4. The allowed cost and change scope: what it may cost (money for tools, shelving or
   insurance, volunteers' time) and how far it may reach (for example how much the
   room may be changed, whether new building rules or agreements are in scope).

Fail if any of the four is neither asked for nor stated as a draft or assumption.
