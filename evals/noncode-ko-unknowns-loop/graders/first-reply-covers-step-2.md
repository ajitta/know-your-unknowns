The user wrote in Korean; the reply may be in Korean. The user wants to introduce an
in-house mentoring programme at their company of 80 employees; they are the only
person in HR, and the CEO is in favour. The reply must cover four things. An item
counts when the reply asks the user for it, or states it as a draft or an assumption;
naming it only as something to settle later does not count. All of these must hold:

1. The outcome the user is ultimately after: what the programme is for (for example
   faster onboarding, keeping people, growing future leads), not only running it.
2. The done criteria: what must be true for the programme to count as working (for
   example a set number of mentor-mentee pairs meeting regularly by a date, a
   participation or satisfaction target, a review point with the CEO).
3. What already works and must not break (for example teams' workloads and deadlines,
   existing onboarding or performance review processes, the CEO's support).
4. The allowed cost and change scope: what it may cost (budget, mentors' hours, the
   user's own time as the only HR person) and how far it may reach (for example all
   80 employees or a pilot group, whether other HR policies may change).

Fail if any of the four is neither asked for nor stated as a draft or assumption.
