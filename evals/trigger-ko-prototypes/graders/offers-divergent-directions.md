The response offers several distinct design directions for the user to react to. All of these must hold:

1. It presents at least 3 clearly separate options (4 is the expected default), not one design with variations of a single detail.
2. Each option states the design philosophy behind it -- what it optimises for and what it gives up -- so the options differ in kind, not only in colour or spacing.
3. It invites the user to react to or pick among them rather than demanding a full written specification first.

Fail if it produces a single design, or if it turns into a list of engineering tasks.
