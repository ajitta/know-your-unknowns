# Approved plan: Riverside Tool Library pilot (6 months, March-August)

Outcome: residents borrow tools instead of buying them, so the neighbourhood spends less and stores less.

Done criteria:

1. 150 members by the end of month 6.
2. 600 loans over the six months.
3. Loss rate under 5% of loans.
4. The volunteer rota covers every opening hour (Saturday 10-14, Wednesday 17-20).

Budget: $18,000 from the Neighbourhood Fund. A $20 refundable deposit per member protects the stock.
