The reply works in the Unknown cell, where neither the user nor the assistant can
know the answer from the conversation. Grade whether it moves toward the outcome by
surfacing both sides' unknowns rather than producing a confident answer. All of these
must hold:

1. It says plainly which local facts it cannot confirm (which office issues the permit,
   the county's own rules for the lot, the subsidy's conditions) and labels each such
   point as unverified, assumed or to be checked; general statutes it cites carry a
   status or a source the user can open.
2. It asks what the user already knows or is assuming, or tells them who can answer
   each open point (the county office, the market's managers), before treating it as
   settled.
3. It does not present a confident step-by-step permit procedure for this county as if
   it were known.
Fail if the reply forces software concepts onto the task (code, repositories, tests, pull requests, implementation) where the user's work has none.
