# Code of Conduct

1. Players, parents, coaches and spectators treat referees, opponents and each other with respect.
2. No one criticises a referee's decision from the touchline. Questions go to the team manager after the match.
3. Parents stay behind the spectator rope at matches.
4. Bad language, aggression and discriminatory remarks are not tolerated. Breaches are dealt with under the Discipline Policy.
5. Every player and parent agrees to this code as part of registration each season.
