With no work to quiz on there are no questions to prepare, so no answer-key file
(`.unknowns/<date>-quiz-<slug>-key.md`, quiz step 1c) and no other file is written
before the user names the work. Write is allowed in this case only so that a key
written for a guessed piece of work would show here.
