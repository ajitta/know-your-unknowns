A working loop for uncertain tasks

Use /unknowns:loop for a larger task, or invoke a single skill when you need one focused step.

Investigate first

blindspot inspects the work ahead. teach-me explains unfamiliar terms. interview helps turn missing decisions into a clearer request.

Plan with room to change

prototypes, brainstorm, and reference explore options. plan orders decisions by how likely they are to change.

Review the work

notes records plan deviations. quiz checks understanding before merge. buy-in helps explain the result to reviewers.

Install in Claude Code

Run these commands inside a Claude Code session. Start a new session or run /reload-plugins, then try /unknowns:blindspot test.

This plugin packages a method inspired by Thariq Shihipar's Know your unknowns examples. Its benefits are design goals; the project has not yet measured them as outcomes.
