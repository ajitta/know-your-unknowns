## 열 정의

- **몰랐던 것 발견?** — 실행 전에는 몰랐다고 사용자가 인정하는 사실만 "예". 산출물이 길다는 것은 신호가 아니다.
- **결정 변경?** — 그 사실 때문에 실제로 바꾼 것(스코프·설계·순서·중단)이 있을 때만 "예". "바꿀 뻔했다"는 아니오.
- 둘 다 "아니오"인 행도 반드시 남긴다. [value-contract.md](value-contract.md)의 강등·제거 조건은 0건 기록으로만 발동한다.

## 직접 기록하는 법 (설치자용)

v0.4.0부터 `/unknowns:loop`의 10단계와 `/unknowns:quiz` 마무리가 이 행을 **자동으로 물어보고 쓴다**
(`.unknowns/scorecard.md`, 규격은 [skills/loop/references/scorecard.md](../skills/loop/references/scorecard.md)).
아래는 그 두 경로를 쓰지 않을 때의 수동 절차다.

위 표는 **플러그인 자체 사용 기록**이다. 설치자는 여기 쓰지 말고 자기 저장소에 사본을 둔다.

1. 위 표의 헤더 2줄을 자기 저장소 `.unknowns/scorecard.md`로 복사한다.
2. blindspot/loop/interview 등을 한 번 돌릴 때마다, 작업 직후 기억이 남아 있을 때 아래 빈 행을 채워 1행 추가한다.

   ```
   | N | YYYY-MM-DD | <과제 한 줄> | <사용 스킬> | 예/아니오 — <몰랐던 사실> | 예/아니오 — <바뀐 결정> | <메모> |
   ```

3. 10행이 모이면 "결정 변경 = 예" 비율을 세어 계약 3번 지표(≥ 50%)와 대조하고, 미달이면 계약 4·5번 조건을 적용한다.
4. 기록할 사용이 없던 기간도 데이터다 — 마지막 행 이후 경과 일수가 계약의 60/120일 시계다.
