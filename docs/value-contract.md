# unknowns 플러그인 가치 계약

작성: 2026-07-11 · 개정: 2026-09-06(강등·제거 조건을 릴리스 계수에서 달력으로 교체).
v0.3.0 사각지대 보고서 항목 "loop step 10 미적용" 대응.
loop 10단계(가치 리뷰: 지표 + 제거 조건)를 플러그인 자신에게 적용한 문서.
아래 수치는 전부 **잠정값**이다 — 측정을 시작하려고 정한 초기값이며 확정치가 아니다.

## 핵심 계약 (5줄)

1. **누구의 문제**: 작성자(및 설치자)가 강한 모델과 일할 때 지도(계획)–영토(현실) 격차를 보지 못하는 문제.
2. **가치 신호**: blindspot/loop 실행이 **사용자가 실제로 몰랐던 사실**을 드러내고, 그것이 **구현 결정을 바꿀 때**만 가치가 있다. 산출물 분량은 신호가 아니다.
3. **지표**: 실사용 10회 롤링 윈도우에서 "결정 변경 유발" 비율 ≥ 50% ([value-scorecard.md](value-scorecard.md)에 기록).
4. **강등 조건**(잠정): 어떤 스킬이 **처음 5회 사용에서 결정 변경 0회**면 README 추천 흐름에서 뺀다. 삭제가 아니라 강등 — 스킬 자체는 남는다.
5. **제거 조건**(잠정): 스코어카드 신규 행이 **60일간 0건**이면 README에 "미측정(unmeasured)"으로 표기하고, **120일간 0건**이면 유지보수 모드를 선언한다.
   릴리스 수로 세지 않는다 — 미사용 상태에서는 릴리스가 나오지 않아 릴리스 계수기는 조건이 필요한 바로 그 상황에서 멈춰 있다.

튜닝 대상 수치: 5회(강등), 10회 윈도우, 50%, 60/120일 — 실측 10행이 모이면 재검토한다.

|--------|---------------------|------|---------|------|
| 2026-09-06 | 2026-07-11 (총 1행) | 57일 | 0건 | 60일 경계 직전. 다음 확인에서 넘기면 README "미측정" 표기 |

스코어카드 행이 아니라 **측정 시계의 첫 데이터점**이며, 이번 개정의 근거다. 같은 57일 동안 릴리스도 0건이었으므로 구 제거 조건("두 릴리스 연속 기록 0건")으로는 아무 조건도 발동하지 않았다.
