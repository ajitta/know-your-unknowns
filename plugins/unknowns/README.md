# Know Your Unknowns (unknowns)

Eleven skills for finding blind spots, learning domain vocabulary, clarifying requirements, comparing options, planning, recording deviations, and checking understanding. The loop skill threads these methods together before, during, and after implementation. Claude Code also gets two agents and two hooks for investigation, review, and deviation reminders.

For installation, worked examples, limitations, and attribution, read the [repository README](https://github.com/ajitta/know-your-unknowns#readme).
