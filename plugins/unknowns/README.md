# Know Your Unknowns (unknowns)

Eleven skills for finding blind spots, learning domain vocabulary, clarifying requirements, comparing options, planning, recording deviations, and checking understanding. The loop skill threads these methods together before, during, and after implementation. Deliverables are Markdown in the conversation. Claude Code also gets two agents for investigation and review; other hosts use labeled passes performed by the assistant. Deviation logging is part of the skill instructions.

For installation, worked examples, limitations, and attribution, read the [repository README](https://github.com/ajitta/know-your-unknowns#readme).
